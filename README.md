# staff-management-system
1. Sistema de Gestão de Funcionários
📌 Sobre o Projeto

Sistema desenvolvido para gerenciar o quadro de colaboradores de uma empresa. O software permite o controle completo do ciclo de vida do funcionário na organização, desde o cadastro até a remoção, utilizando identificadores únicos (IDs) para garantir a integridade dos dados.
📌 Funcionalidades

    Cadastro de novos funcionários com ID gerado automaticamente.

    Consulta detalhada com três filtros:

        Listagem completa de todos os colaboradores.

        Busca específica por ID.

        Filtragem de funcionários por setor.

    Remoção de registros do sistema através do ID.

    Interface via terminal com menus interativos e validações de entrada.

📌 Tecnologias Utilizadas

    Lógica de programação avançada.

    Estruturas de dados (Dicionários e Listas).

    Modularização com funções.
