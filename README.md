# staff-management-system
# Sistema de Gestão de Funcionários

Projeto desenvolvido para gerenciar o quadro de colaboradores de uma empresa, permitindo o controle completo desde o cadastro até a remoção, utilizando identificadores únicos para garantir a integridade dos dados.

---

### 📌 Funcionalidades

* Cadastro de novos funcionários com ID gerado automaticamente
* Consulta detalhada com listagem completa de todos os colaboradores
* Busca específica de funcionário por ID
* Filtragem de funcionários por setor
* Remoção de registros do sistema através do ID
* Interface via terminal com menus interativos e validações de entrada

---

### 📌 Tecnologias Utilizadas

* Lógica de programação avançada
* Estruturas de dados (Dicionários e Listas)
* Modularização com funções
